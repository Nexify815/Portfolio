Student Report Automation & PDF Export

Generates termly STEM assessment report cards from Google Sheets and exports them as PDFs to Drive, in batches, within Apps Script's execution limit.

The problem

An educational robotics programme needed termly evaluation reports for every student, each with logos, nine assessment categories, colour-coded scores and a signature block. Producing those by hand is slow, inconsistent and easy to get wrong.

What I built

An Apps Script project bound to a “Class Details” sheet. A sidebar asks for the school name, term and batch size, then generates a formatted report sheet for each student and exports the finished PDFs to a chosen Drive folder.

01

Reads from the sheet

Student names, grades and scores across nine weighted criteria are read directly from the Class Details sheet.

02

Batched runs

Configurable batches using time-based triggers, staying inside Apps Script's six-minute execution limit.

03

Formatted reports

Logos, score breakdowns with descriptions, colour-coded results and a signature section.

04

PDF into Drive

Generated batches export to PDF; source spreadsheets are trashed after a successful download.

Assessment model

Nine criteria total 100 marks: Presentation Skills, Teamwork, Time Management, Engineering Design, Critical Thinking, Class Participation, Class Work and Homework at 10 each, plus the Assessment itself at 20.

Decisions that mattered

Config cells instead of code edits

Five cells in the sheet (logo, signature, company logo, Drive folder and authority title) retarget the generator at another school.

Batched runs on triggers

A single Apps Script execution cannot exceed six minutes, so runs are chunked and scheduled.

An observable long run

A progress bar, cancellation and a report-link view make a multi-batch job something you can watch.

PDF into Drive

Because that is how the reports are actually distributed.

Outcome

Termly reporting that runs from a sidebar instead of occupying an instructor for days.
