Case study

Offline-First LAN Examination System

A computer-based exam system for school computer labs that runs entirely on the local network, and is simple enough for non-technical teachers to operate.

Role
Design & full-stack development
Stack
Node.js, Express, Socket.io, SQLite
Platform
Self-hosted on a school LAN

Screens

The problem

School computer labs often have the machines but not a reliable internet connection, and exam day is exactly when a dependency on the cloud is most dangerous. The system also has to be operable by teachers who are not technical.

What I built

A computer-based examination system designed for school computer labs. It runs entirely offline within a local area network and covers the full exam lifecycle, from creating an exam to monitoring the room and grading the results.

  • Teacher dashboard to create, manage and monitor exams.
  • Live student tracking over Socket.io, so the room is visible as it happens.
  • Three question types: multiple choice, true/false and short answer.
  • Auto-grading for objective questions, with instant results.
  • Import and export in CSV, Excel and JSON.
  • Exam integrity measures: fullscreen enforcement and tab-switch detection.

How it is built

Express serves an EJS front end backed by SQLite through better-sqlite3, while Socket.io pushes live state to the teacher's dashboard. ExcelJS and PapaParse handle bulk imports, so staff can prepare students and questions in the spreadsheets they already use.

Decisions that mattered

  • SQLite over a server database. A single self-contained file travels with the install and needs no administration.
  • Socket.io for monitoring. The teacher sees the room live instead of refreshing a page.
  • Server-rendered EJS and vanilla JavaScript. The client stays light enough for older lab machines.
  • Fullscreen and tab-switch detection. An unsupervised digital exam needs guardrails.

Outcome

A self-contained exam system a school can deploy on its own network and run without an internet connection at any point.
