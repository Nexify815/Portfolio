Auto Cat: Intelligent Downloads Organizer

A quiet, always-on filesystem service that waits for downloads to finish, reads what is inside them, and files them where they belong.

Role
Design & development
Stack
Python 3.11, Windows tray
Platform
Background desktop service

Screens

The problem

Downloads folders rot because filing has to happen at the exact moment you least want to do it. Filenames rarely tell you what a file actually is, either.

What I built

A filesystem service that watches a folder, detects new files and browser temp-name to final renames, and waits until a file's size has been stable for a few seconds. It then identifies the file by reading PDF text to tell an invoice from a statement from a contract, and extracts the date and vendor to build a clean name.

  • Wait-until-done. Partial .crdownload and .part files are ignored.
  • Content intelligence. PDF text decides the category and supplies the date and vendor for names like 2026_July_Acme_Power_Electric_Bill.pdf.
  • Rules-driven. Categories, keywords and extensions live in a commented config.yaml, so no code changes are needed to retune it.
  • Quiet by default, with an optional Windows tray icon and logon auto-start.

Safety model

Nothing is ever destroyed, and every move can be reverted.

  • Same-volume moves are atomic renames; cross-volume moves copy, verify a SHA-256 hash, then delete the source.
  • Uncertain files are never touched, so they stay in the watched folder.
  • Every action is logged with an id, and --undo <id> restores it, deduping instead of overwriting.
  • --dry-run previews every decision without touching a file.

Engineering

The project ships with a test suite of 65 tests and Ruff for linting, plus a setup window that asks which folder to organise and writes the config.

Outcome

A downloads folder that stays organised without anyone remembering to organise it.
